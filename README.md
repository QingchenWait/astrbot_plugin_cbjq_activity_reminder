# astrbot_plugin_cbjq_activity_reminder

✨ [AstrBot](https://github.com/AstrBotDevs/AstrBot)《尘白禁区》活动日历+自动提醒插件 ✨

[![Python 3.9+](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/)
[![GitHub](https://img.shields.io/badge/作者-青尘工作室-blue)](https://space.bilibili.com/385556208/)

</div>

- **实时活动日历**：自动解析《尘白禁区》活动日历，展示 [开放活动剩余天数] 与 [未来活动倒计时]。
- **地下清理日历**：根据管理员配置的地下清理参考日期，自动计算当前周期和剩余天数。
- **活动结束提醒**：活动或地下清理将在 1 天内结束时，在特定时间点发送提醒。
- **自定义配置**：可自由配置日历统计方法、bot 文案、发送活动结束提醒的时间和名单。



### 🎯 使用方法

- 可以通过 `@机器人 <日历指令>` 或 `/<日历指令>` 的方式，进行日历查询或自动提醒开关的配置。

  例如：`@机器人 cbjq` 或 `/cbjq` ，即可查询尘白禁区当期活动日历。

- 可以使用的 `<日历指令>` 包括：

  | 日历指令                        | 可使用的角色         | 功能说明                         |
  | ------------------------------- | -------------------- | -------------------------------- |
  | `cbjq`、`尘白活动` 、`尘白日历` | 所有人               | 查询完整的尘白禁区当期活动日历。 |
  | `cbjq_refresh`、`尘白刷新`      | AstrBot 管理员       | 清空缓存，重新拉取活动日历。     |
  | `尘白订阅提醒`                  | 群主、AstrBot 管理员 | 开启 “活动结束前自动提醒” 功能。 |
  | `尘白取消提醒`                  | 群主、AstrBot 管理员 | 关闭 “活动结束前自动提醒” 功能。 |



### 🛠️ WebUI 配置项

在插件的 WebUI 界面，需要优先配置以下项目：

| 配置项                   | 默认值     | 说明                                                         |
| ------------------------ | ---------- | ------------------------------------------------------------ |
| 允许通过 @机器人 查询    | `true`     | 如果开启，则允许通过 `@机器人 <日历指令>  ` 查询。<br />如果关闭，则只能通过 `/<日历指令>` 查询 |
| 过去某次地下清理开始日期 | 2026-05-01 | 某次地下清理开始日期，建议格式为 `YYYY-MM-DD`。<br />输入过去或未来的任何一次地下清理开启日期均可。 |
| 启用自动提醒             | `true`     | 只有开启该选项，才会发布自动提醒。                           |
| 自动提醒会话列表         | `[]`       | 推荐让 QQ 群主在群聊内使用 `/尘白订阅提醒` 订阅命令，实现自动写入。<br />如果了解相关规范，也可以手动写入。 |
